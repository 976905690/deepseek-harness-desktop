## 2026-09-09 工作笔记（接续）

#### 报错：`Cannot find module '.../node_modules/dsh-image-video/lib/index.js' imported from .../dsh-plugin-desktop/lib/index.js`

**根因**（用户问"是不是我改错了？"——答：和我之前的 bootstrap 脚本无关）：
- `dsh-image-video/.gitignore` 里把 `lib/` 排除了，构建产物**不进 git**
- 同事 `git submodule update` 只拉源码，`lib/index.js` 不存在
- 而根 `package.json#scripts.dev` 只 build 了 `dsh-community-market` 和 `dsh-plugin-desktop`，**从未 build `dsh-image-video`**
- cordis loader 启动时调 `import('dsh-image-video')` → 找不到 `lib/index.js` → 报错

**复现验证**：清空 `dsh-image-video/lib/` 后从 `dsh-plugin-desktop` 用 `node -e "import('dsh-image-video')"` 跑 → 100% 复现用户报错。

**修复**（不需要删项目、不需要重新 clone）：
- 根 `package.json` 的 `build` / `dev` / `package:dir` / `dist:mac` / `dist:mac-smoke` / `dist:win` / `dist:win-portable` **最前面**加 `yarn workspace dsh-image-video build`
- 同事只要跑 `corepack yarn dev`，脚本链自动 build dsh-image-video → build market → build desktop → 启动 GUI

**验证**（清空 lib 后跑 `corepack yarn dev`）：
- ✅ `yarn workspace dsh-image-video build` → 产物生成
- ✅ `yarn workspace dsh-community-market build` → 成功
- ✅ `yarn workspace dsh-plugin-desktop dev` build → 成功
- ✅ bootstrap 检测 threerouter.apiKey 已配置 → 跳过
- ✅ **完全没出现 `Cannot find module` 报错**
- 余次只剩 sandbox 无 GUI 导致 Electron 启动失败——本地 macOS 桌面正常

**同事首次 clone 命令**（已写进 `docs/plugin-topology.md`）：
```
git clone <repo>
cd deepseek-harness-desktop
git submodule update --init --recursive
corepack yarn install --immutable
corepack yarn dev
```

**教训/后续**（值得沉淀）：
- "git submodule + lib/ 不进 git" 是经典的"submodule 产物陷阱"。要么 prebuild + 不入 git（要靠 dev 脚本兜底），要么改用 `git lfs` 存产物，要么把构建脚本也写进子模块 `prepare` 让 `yarn install` 时自动 build。
- 我已修对 dev 脚本；后续如要更稳，可以考虑给 `dsh-image-video/package.json` 加 `scripts.prepare = "yarn build"`，这样 `yarn install` 链路里就会自动 build（不用再靠 dev 兜底）。但要小心 `corepack yarn install --immutable` 是否会触发 prepare。**本次未做，先记一笔。**
