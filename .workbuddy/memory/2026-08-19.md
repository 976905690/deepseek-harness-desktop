## DSH Desktop 黑屏 + 窗口标题排查

- 现象：advanced 模式启动后主区域透明/黑屏，窗口无标题「Threerouter Harness」。
- 结论（黑屏侧）：截图中的绿勾调试日志在 src/ 与 lib/ 全仓库 0 命中，非当前代码生成，疑似旧调试 overlay 残留，未在仓库内找到注入点。
- 结论（标题侧）：Windows advanced 模式 `window-options.ts` 用 `titleBarStyle:'hidden'` + `titleBarOverlay`（只画窗控按钮），原生标题栏被隐藏；`electron-runtime.ts` 的 `preserveBlankTitle` 还 preventDefault 掉所有 `page-title-updated`；caption row 只有 drag 区域没有文字 → 标题本就不显示，属设计行为。
